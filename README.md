# sand

Games built with Claude.

| Folder | What it is |
| --- | --- |
| [`sandcastle-cays/`](sandcastle-cays/) | A calm sandcastle-building game. You live on a small sailboat and sail between Caribbean island beaches. Runs in the browser on phone and laptop. |
| [`wind-wing-wave/`](wind-wing-wave/) | An island-making game (working name: Wind, Wing & Wave). Shape land from the sea with lava, rock and sand; life arrives on its own on the wind, on wings and on the waves. Built from the Sandcastle Cays engine. |
